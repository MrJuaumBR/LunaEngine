Apply a preset or custom cursor source and return success.

Custom sources may be a ``pygame.Cursor``, ``pygame.Surface``,
``AtlasItem``, ``Icon``, ``pathlib.Path``, string path, or graphics
``Image``. Custom image cursors use a centered hotspot and are cached
by source identity. Invalid sources warn, fall back to the arrow, and
never raise.
